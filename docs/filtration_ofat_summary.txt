regressing (pore_size x flow_rate) on [1, pore_size, flow_rate] in the OFAT design: R^2 = 1.0000000000
R^2 = 1.0 means the interaction column carries zero information beyond what the two main
columns already carry in this design; it is exactly, not approximately, confounded.

=== Evidence 2: design matrix rank when the interaction term is forced into the model ===
columns in [const, 4 main effects, pore_size:flow_rate]: 6
numerical rank of that design matrix: 5
rank deficient: True
statsmodels OLS still returns a coefficient via pseudo-inverse when asked (estimate=-8.8281, std_err=0.8915930411581656), but with a rank-deficient design this coefficient is not identifiable: it is the minimum-norm solution among infinitely many that fit the OFAT data equally well, not a unique estimate of the interaction, and its standard error is undefined (statsmodels reports it via a generalized inverse, not a real sampling distribution). The true seeded interaction, +3.0, cannot be told apart from 0 or any
other value using only this design; the honest conclusion is 'not estimable', not 'estimated as -8.83'.

=== Conclusion ===
The filtration factorial design's own effect table (docs/filtration_factorial_summary.txt)
flags pore_size:flow_rate significant on the identical 80-run budget. The OFAT
design, which never varies both factors away from baseline in the same run, cannot estimate
that interaction at all: it is exactly confounded with the two main effects (R^2 = 1.0 above),
not merely underpowered to detect it.
