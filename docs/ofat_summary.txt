=== Evidence 2: design matrix rank when the interaction term is forced into the model ===
columns in [const, 5 main effects, ink_pressure:nozzle_drive_voltage]: 7
numerical rank of that design matrix: 6
rank deficient: True
statsmodels OLS still returns a coefficient via pseudo-inverse when asked (estimate=-4.4570, std_err=0.1814970982151087), but with a rank-deficient design this coefficient is not identifiable: it is the minimum-norm solution among infinitely many that fit the OFAT data equally well, not a unique estimate of the interaction, and its standard error is undefined (statsmodels reports it via a generalized inverse, not a real sampling distribution). The true seeded interaction, +4.0, cannot be told apart from 0 or any
other value using only this design; the honest conclusion is 'not estimable', not 'estimated as -4.46'.

=== Conclusion ===
The factorial design's own effect table (docs/factorial_summary.txt) flags
ink_pressure:nozzle_drive_voltage significant on the identical 96-run budget. The OFAT design, which
never varies both factors away from baseline in the same run, cannot estimate that interaction
at all: it is exactly confounded with the two main effects (R^2 = 1.0 above), not merely
underpowered to detect it.
